# Color-Studio
Color Studio 🎨  A minimalist, utility-first Color Palette Generator &amp; WCAG Contrast Checker built with vanilla HTML, CSS, and JavaScript. Generate harmonious random palettes, lock your favorite shades, check real-time accessibility contrast scores, and save palettes locally in your browser.

✨ Features: Instant Palette Generation: Click Generate or press the Spacebar to shuffle colors smoothly.Lock Individual Colors: Freeze specific shades while regenerating the remaining columns. One-Click Hex Copy: Click any hex code to copy it straight to your clipboard with an animated toast confirmation.Live WCAG Contrast Checker: Automatically calculates the relative luminance and contrast ratio (1:1 to 21:1) against white and black, displays an AAA, AA, or Fail badge, and dynamically adapts text color for maximum readability.Saved Palettes Drawer (localStorage): Save your favorite 5-color combinations, view them as mini swatch strips in a slide-out drawer, reload them with one click, or delete them anytime—persisted across browser sessions.Fully Responsive: Adapts seamlessly from a 5-column desktop grid to a 2-column tablet layout and 5 stacked horizontal bands on mobile devices.🛠️ Tech StackHTML5: Semantic structure (<header>, <main>, <section>, <aside>) and accessible ARIA attributes.CSS3: CSS Grid, Flexbox, CSS Custom Properties (:root), smooth GPU-accelerated transitions, and responsive @media queries (1024px & 600px breakpoints).JavaScript (ES6+): Pure vanilla JS with no external libraries or frameworks.Event delegation & keyboard listenersnavigator.clipboard API (async/await)localStorage API with JSON serializationWCAG 2.1 relative luminance & contrast ratio math📁 Project Structurecolor-studio/
